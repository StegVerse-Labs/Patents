## Required event records

Create one row for each relevant event. Do not combine events that occurred on different dates or involved different contributors.

|---|---|---|---|---|---|---|---|

## Event types

- first articulation of multi-entity observer-participant governance;
- first description of separate proposal, performance, observation, or review roles;
- first formalization of local versus global coherence;
- first description of observer evidence without execution authority;
- first receipt-reconciliation or shared-state reconstruction design;
- first executable prototype or test;
- first internal disclosure to another person;
- first public post, paper, repository release, demonstration, or offer;
- correction, supersession, or material expansion of an earlier concept.

## Required source detail

For each event, preserve:

```text
repository or system
exact path, message, issue, PR, paper, or recording
commit or immutable identifier when available
author or participant identity
timestamp source
confidentiality status
what technical content was actually disclosed
whether the record predates or supersedes another record
```

## Public-disclosure audit

For every potentially public event, answer factually:

1. What exact material was accessible?
2. On what exact date did access begin?
3. Was the disclosure enabling, partial, conceptual, or merely referential?
4. Which candidate limitation clusters were present?
5. Were implementation details present?
6. Was access restricted, private, confidential, or public?
7. Is there an immutable copy or archive?

Legal consequences must be determined by qualified counsel. This repository must not calculate a deadline from an unverified disclosure event.

## Contributor intake

For each person who may have contributed, preserve:

```text
name
contact information
employer or affiliation at the time
specific technical contribution
first known contribution date
supporting records
whether contribution appears in a candidate limitation cluster
assignment or employment documents, if any
```

Do not infer inventorship from authorship, repository access, employment, discussion participation, or project leadership.
