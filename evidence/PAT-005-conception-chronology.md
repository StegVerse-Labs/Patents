## Required Evidence Collection

For each independent-claim limitation, collect:

1. earliest conversation, notebook, drawing, or design note expressing the complete concept;
2. earliest repository implementation or executable demonstration;
3. earliest test or receipt showing the limitation operated as intended;
4. earliest public disclosure;
5. each human contributor's description of their conceptual contribution;
6. evidence distinguishing conception from implementation, testing, documentation, and prompting.

## Disclosure Audit Targets

- GitHub repositories and commit history;
- GitHub Pages and StegVerse websites;
- Publisher papers and data artifacts;
- LinkedIn posts and comments;
- uploaded documents and chat exports;
- direct messages or external review packages;
- screenshots only where primary machine-readable evidence is unavailable.

## Chronology Boundary

A later comprehensive document does not replace earlier conception evidence. A repository commit proves that content existed in that repository by that commit, but does not by itself prove who conceived each claimed limitation or when conception first occurred.
